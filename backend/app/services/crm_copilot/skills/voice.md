# voice

Spoken messages are already transcribed into the same user text as a typed message.
Do not treat voice as a special pipeline. Never call extract_sales_update just because it was spoken.
If last_contact_id is set and they dictate a fact or recap with no field changes, create_note.
Only extract_sales_update when they recap a full sales call with amount, stage, or several CRM fields.
Never preview_write / apply_write an empty "Solo contacto" card.
